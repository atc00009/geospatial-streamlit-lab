# Chicago Geospatial Analysis & Interactive Lab

An interactive Streamlit application designed for students to explore spatial point vectors, aggregated polygon choropleths, and statistical response metrics across Chicago.

## Project Structure
- `app.py`: Main Streamlit web application.
- `requirements.txt`: Python package dependencies.
- `.gitignore`: Configured to protect secrets and ignore temp files.

## Features
- Toggle between **Point Vector**, **Choropleth Polygon**, and **Folium Map** layers.
- Interactive filtering by incident severity.
- Real-time KPI calculations and response time distribution charts.
- Guided critical thinking prompts for students.
